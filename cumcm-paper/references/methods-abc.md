> 选题、建模、选方法、设计求解与灵敏度时读本文件。题号不绝对决定方法，先判问题本质（机理计算 / 统计推断 / 预测 / 评价 / 优化 / 网络 / 系统分析）再选方法，**反对方法堆砌与算法名投票**。

## 1. 选题与问题操作化

- 全员先**独立**读题面与全部附件，暂不讨论算法；各写一句话问题定义、每问输入/输出、硬约束、评价指标、主要歧义与风险，再集中比对，防止第一个顺口解释直接成全队结论。
- 把自然语言转成可计算对象，建「题问—交付矩阵」：每问登记 给定输入 / 可观测量 / 待求量 / 决策变量及取值域 / 硬约束 / 必答输出（含单位精度、规定文件名）/ 评价指标 / 基线 / 验证方式 / 所需图表 / 论文位置。
- 区分「题目已知 / 常识或文献事实 / 本文假设」；需要外部事实首次出现处标参考文献。
- 建模思路写清各问依赖：前问提供什么参数/结构，后问新增什么；各问独立也要说明共享的数据处理与验证。

## 2. A 题：连续型 / 机理建模（物理、工程、几何）

**特征**：给物理/工程背景、几何结构与定律，重底层机理推导，结果常是确定的、可解析或高精度数值解。

**标准路径**
1. 画机制/几何示意图，定义坐标系与全部符号、单位。
2. 由守恒律（质量、能量、动量、电荷、热量）或几何关系建立方程：微分方程（常微/偏微，如热传导 cρ∂u/∂t=∂/∂x(k∂u/∂x)）、积分方程、代数方程组。
3. 写全初始条件、边界条件（Dirichlet/Neumann/Robin/混合）、多介质交界面连续条件（u⁻=u⁺，(k∂u/∂x)⁻=(k∂u/∂x)⁺）。
4. **分情形讨论**：几何/工况分情形（情形 1…n），每种给成立条件与对应公式，条件切换处显式判断。
5. 数值求解：有限差分（优先隐式/克兰克-尼科尔森保稳定，显式注意 CFL）、有限元；线性化后常得三对角方程组，用追赶法(Thomas)；写网格/步长收敛性（加密一倍结果变化<容差）。
6. 有解析解/退化情形一定对照验证；量纲、守恒、极端参数退化到已知关系。
7. 若末问是设计/控制，建优化模型：目标、变量、约束、可行域；多目标用加权/帕累托/字典序，说明转化依据。

**关键要求**
- 推导一步步写，不直接抛最终式；每个符号解释、公式编号、正文引用。
- 边界条件选取、显式 vs 隐式稳定性、解析解对照、结果检验是评委重点。
- 角度内部用弧度，仅输入输出换算度；单位全文一致。

**A 题评委常批 8 问题**：模型不完整；计算方法不清楚；计算结果不完整；没很好呈现结果；没对结果分析；没有结果文件或格式不对；没进行理论分析；没给出具体优化模型。

## 3. B 题：离散型 / 运筹优化、定位调度、参数反演

**近年题谱**：2021 C4 烯烃（统计+优化）、2022 无人机纯方位无源定位、2023 多波束测线（几何覆盖+路径）、2024 生产决策（运筹+抽样检验）、2025 碳化硅外延层厚度（光谱反演+非线性最小二乘）。

**常见子类与做法**
- **几何/覆盖/布局**：坐标与向量关系、射线-三角形求交、视场角/入射角判定、覆盖矩阵；连通盲区用并查集/BFS；说明射线过边/顶点、近似共面、浮点容差处理，且**不得靠改网格/放宽阈值消除数值不稳定**。
- **路径/调度/选址(TSP/VRP/网络)**：在给定图上建 0-1 决策变量与流平衡/消圈约束；字典序目标（先最少位姿数再最短时间等）严格按题面；启发式给编码、邻域、终止准则、收敛曲线与多初值。
- **参数反演/信号辨识**：先把**理论模型表达式 R_theo(ω;d) 显式推导清楚**（反射率/透射率/折射率随入射角、波长的关系，不能把衬底折射率当常数）；再建非线性最小二乘 min Σ(R_obs−R_theo)²。
  - 非线性 LS 最大陷阱是**过早陷入局部极小**：多初值网格 + 全局优化(遗传/模拟退火/多起点 L-M)，报告收敛到同一解的比例；用不受干扰的特征量（如不受多次反射影响的波峰坐标）分区间计算，再做统计，报均值、标准差、95% 置信区间。
- **动态系统/机理+数据混合**：从守恒建状态空间（质量、能量、传感器一阶滞后），参数可辨识性分析——说明哪些参数可稳定辨识、哪些只能辨识组合；用未参与拟合的工况交叉验证；故障/异常诊断写成带复杂度惩罚(AIC/BIC)的模型选择，不靠单曲线肉眼判断。
- **最优控制**：离散控制变量、变化步长约束、状态/安全约束；字典序目标；对输入扰动做不确定性分析并给安全裕度。

**B 题关键**：理论式必须写清；防局部极小；结果给统计量与置信区间；优化六要素与字典序/并列规则写全。

## 4. C 题：数据型 / 统计建模

**定义**：基于业务理解整合多属性数据，经可视化/统计分析建模，获得信息辅助评估、排序、分类、预测、决策。
**流程**：数据导入与预处理 → 描述性/统计分析 → 深度挖掘（评价/预测/分类）→ 评估/预测/决策。

### 4.1 数据预处理（每条处理都要能辩护）
- 先做数据审计并列表记录：粒度/主键、时间范围、单位、连接规则、缺失（比例/是否成片）、异常（物理越界/统计离群）、重复、量纲、时空/分组依赖。
- **命题人红线**：大数据那套填充/修改/删减在非大数据数模题里慎重；任何处理以**不改变问题本质**为原则，并说明对结论的影响。缺失优先「保留并建模/删除并说明」，慎用均值/插值填充；异常先判来源再决定。
- **口径统一**：规格换代用 canonical 映射与标准份折算；指标口径版本切换用对照样本校准；退货/记账滞后按发生时点对齐。

### 4.2 严防信息泄漏（C 题分水岭）
- 画信息时间线：预测时刻哪些字段可见。事后生成字段（缺货分钟数、销售排名、退货记账、标签）**不得**当事前预测输入；标准化/特征选择/降维只在训练折拟合，禁止用全样本统计量。
- 严格按题面切训练/验证/测试（如 1–120 训练、121–150 指定验证、151–180 结构稳定性检查）；促销分随机试验/系统定向/节假日，因果效应优先用随机试验子集识别，用全样本要解释选择偏差。
- 区分「原始意向需求 / 实际履约量 / 净销售收入」：缺货截断、替代转入转出、取消、报损、跨期退货分别进入哪个指标要讲清。

### 4.3 方法选择（适用性 > 高级程度）
- 四类任务：综合评价、综合排序、未来预测、分类预测。常用：回归/广义线性/Logistic、时间序列(ARIMA/状态空间)、弹性/因果模型、树模型/集成、聚类、相关/多重共线诊断、随机优化/仿真。
- **必须设透明基线**（如「最近 7 日需求均值」），复杂模型在同一评价协议(WAPE/RMSE/准确率等)下显著更优才保留。
- 预测报告总体/分组/关键子集误差并与基线对比；给估计不确定性（置信区间/自助法）；样本外再做结构稳定性检验。
- 评价/决策：明确指标含义与权重来源（数据驱动或灵敏度区间），末问常是风险调整优化 max E(Π)−λ·风险，含服务水平/损耗/容量约束，用多情景等概率仿真，与「维持现状」策略对比。

### 4.4 C 题命题人明确反对
- 把风险决策/因果问题简单做成「指标加权综合评价」，综合指标含义不清；
- 乱套 AHP、模糊综合、TOPSIS 等简单线性加权、灰色预测、无检验的回归、无模型的信誉评级；**不匹配的方法要敢舍弃并说明**；
- 堆多种统计方法得到与问题无关的结果；描述统计/可视化形式化、套路化。
- 数据应用无定式：适用性、针对性、合理性最重要，**机理分析不可少**；注意时效性、季节性、周期性、突变性。

## 5. 通用建模模块

### 5.1 优化模型六要素（缺一不可）
决策变量（及取值域）、目标函数（写明单/多目标与字典序或加权依据）、约束（物理/资源/容量/几何/时序/逻辑/变量边界，列来源）、可行域、求解方法（连续/离散、凸/非凸、精确/启发式及参数）、停止与并列规则。

### 5.2 拟合与预测
定义 ŷ=f(x;θ) 与残差 r=y−ŷ（单位与观测量一致）；损失按噪声特性选（OLS/Huber 稳健/加权/软 L1）；展示数据+拟合+残差；交叉/留出验证；报误差与不确定性；防泄漏。

### 5.3 评价模型
指标标准化（说明正向/负向、量纲）、权重来源与灵敏度、合成规则、排序稳定性；避免黑箱加权。

### 5.4 灵敏度 / 稳健性 / 不确定性（加分关键）
- 检查：参数扰动、数据子集、噪声、模块消融、随机种子、评价指标、计算成本、极端情景；决策问题还要看排序/活跃约束/最优策略是否翻转。
- 结论模板：「在 [扰动范围] 内，[指标] 变化不超过 [数值幅度]，[结构/排序] 保持/改变；超过 [失稳阈值] 后 [如何变]；故建议：若…则…，否则…」。
- 消融：删某模块结论几乎不变，就不把它当卖点；改进只在窄窗口出现，主张收窄到该窗口。
- 不确定性来源（测量/抽样/参数/模型结构/情景/数值）→ 传播方式（解析/重采样/情景扫描/区间）→ 给区间或最坏情形。

### 5.5 三种验证不可互相替代
Verification：代码是否正确实现模型（量纲、守恒、手算小例、制造解、步长收敛、种子复跑）；Validation：模型在目标情景是否合适（留出、残差结构、现实量级、适用域）；决策稳健性：条件变化结论是否翻转。关键结果用另一函数/另一算法/手算独立复核。

## 6. 各题型高频扣分点（建模侧）
- A：不做分情形、边界条件错、显式差分不稳、无解析解对照、直接抛公式无推导、缺具体优化模型。
- B：理论表达式没写清/把变量当常数、陷入局部极小当最优、不给统计量与置信区间、优化要素不全。
- C：乱填充删改、事后字段泄漏、训练测试污染、套不匹配的综合评价/灰色预测、无基线、误差不与基线比。
- 通用：术语算法堆砌、模型选择无理由、无基线对照、只报「效果良好」、结果无单位无误差、灵敏度只写「不敏感」、论文模型与代码实现不一致（能跑但模型错）。
