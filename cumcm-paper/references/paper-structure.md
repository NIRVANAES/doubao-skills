# 数模论文结构与逐章写作指南

> 写/改任意章节、写摘要、组织论文时读。配套 LaTeX 骨架见 `assets/latex-template/main.tex`。

## 目录
1. 整体骨架与组织原则
2. 摘要（决定档次）
3. 各章节写法细则
4. CEWL 结果段与结果呈现
5. 图、表、公式、参考文献、附录代码

## 1. 整体骨架与组织原则

标准顺序（电子版从摘要页开始）：
```
标题（对象+核心任务，18–26字，无副标题）
摘要页（标题+摘要+关键词，单独一页，后另起页）
1 问题背景与重述（问题重述 / 问题分析[配示意图+操作化清单] / 建模思路[总路线图]）
2 模型假设与符号说明（假设带依据与失效影响 / 符号三线表）
3 数据预处理与描述性统计（仅需要时，否则删）
4 问题一建模与求解（分析→建模→求解→结果分析→检验）
5 问题二建模与求解（说明相对问题一的增量，只写新增）
6 问题三建模与求解（递进复用，只列改变的约束/变量）
7 模型稳定性与灵敏度分析（也可分散到各问）
8 模型评价（优点 / 局限与改进 / 推广）
参考文献（另起页）
附录（另起页：支撑材料清单 + 完整可运行源代码）
```

组织原则：
- **按问题分章，每问「分析→建模→求解→结果→检验」**；后问复用前问、只讲增量（不要整段重复前问公式）。
- 大问题拆小问题、多加小标题；能用公式/示意图/流程图/表格就不写大段文字。
- 章节自然连续排版，不强制每章分页；仅摘要、参考文献、附录另起页。
- 论文从第一天搭骨架并随证据同步填充；占位只记「缺什么」，**不填虚构内容**。

## 2. 摘要（重中之重，最后写、素材从第一天攒）

### 2.1 结构（逐问分段）
1. **总起（1–2 句）**：建立了什么总体模型/模型链 + 对象与现实矛盾 + 「模型—原理—算法—验证」总路线；不写口号、不做文献综述，可点一句题目背景。
2. **问题一段**：对象 → 底层规律/数据特征 → 建立什么数学关系 → 什么算法 → **关键数值（带单位/误差/裕度）** → 说明什么。
3. **问题二段**：模型 + 相对问题一新增的未知量/约束及为何扩展 + 估计量/求解策略 + 主要结果 + 与基线比较或稳健范围。
4. **问题三及以后段**：按「任务—依据—模型—结果—意义」压缩；预测报精度、评价报判据、优化报目标改善量与成立条件。
5. **综合验证与边界段**：通过了哪些拟合/残差/灵敏度/对照/极端检验 + 最重要决策建议 + 适用范围 + 一项不可忽略局限。
- 末尾「关键词：」3–5 个（对象、核心关系、任务类型/关键算法），勿与标题机械重复。

### 2.2 铁律
- 段内**先讲模型怎么建立，再给结果**；结果尽量全部在摘要给出（哪怕正文表还没填），每个数字都能在正文图表核验。
- 结果带单位、误差/置信区间/可行裕度；用「在 X 条件下结果为 Y，误差 Z」。
- 禁空话：「建立了 XX 模型，求解得到合理结果/效果良好」一律重写。
- ≤1 页、不附英文摘要、不出现身份信息。

### 2.3 摘要句式模板
- 「针对问题一（……任务），基于（……规律/数据特征）建立（……模型），采用（……算法）求解，得到（……量）为（数值±误差/区间，单位），表明（……结论）。」
- 「问题二在问题一基础上新增（未知量/约束），将模型扩展为（……），以（……）为目标，求得（……），相较基线改善（……），在（……）扰动范围内结论保持。」

## 3. 各章节写法细则

### 3.1 问题重述与分析
- 问题重述确定题目当天即可先写（结果留空）；用自己的话，不照抄题面；区分题目已知/文献事实/本文假设。
- 问题分析 = 把自然语言转成可计算对象：定研究边界，拆输入/待求/决策/硬约束/输出/评价指标；**配变量关系图或机制示意图**。
- 建模思路讲各问依赖与总技术路线（配 workflow 流程图）。

### 3.2 假设与符号
- 每条假设写：「**假设内容 + 依据（题面/尺度分析/数据证据）+ 简化掉什么 + 失效时偏差方向/影响环节**」；假设不是越多越好。
- 符号三线表按首次出现排序：符号/定义/单位或取值域/首次用途；正文每个符号都能在表里找到。
- 角度内部统一弧度；单位负指数写法 cm^{-1}。

### 3.3 建模（核心得分）
- 从定义/机理**逐步推导**：先机制图，再一步步代数变形到可计算式，不跳步、不直接抛最终式。
- 每个公式后逐项解释符号、含义、成立条件；公式连续编号、正文用「式(n)」引用。
- 优化写全六要素；拟合展示数据/拟合/残差与泄漏控制；模型选择给结构层理由 + 基线对照。
- 复杂模型前先有最低可行基线；候选只有在约定指标上做出影响决策的改进才保留。

### 3.4 求解
- 算法用伪代码三线表或流程图，每步可追溯到公式：输入、校验、初始化、循环/分支（写清精确判定条件）、更新规则、停止准则、返回（含单位/不确定性/诊断）；随机算法固定种子、写参数与容差。
- 数值方法写格式、稳定性、步长收敛；启发式给收敛曲线证明非早熟。

### 3.5 结果分析
- **先一句话回答该问**，再上结果表/图，再解释「为什么」（由哪个主导项/规则决定）。
- 结果表列：对象/方案、主要结果(单位)、误差/区间、(可选)约束裕度、(可选)相对基准改善、结论。
- 题面要求的结果表、结果文件（如 result1.xlsx）一个不漏，格式/文件名严格按题面。
- 每个重要结论绑定图表（图证）；数值来自结果文件，不在文字阶段手改。

### 3.6 稳定性/灵敏度/误差
按题型选：机理查量纲/守恒/极端退化/解析对照；统计查拟合/残差/留出误差；评价查权重与排序稳定性；优化查可行性/基准/扰动/约束裕度/最优性。结论给区间与阈值（写法见 methods-abc §5.4）。

### 3.7 模型评价
- 优点：「在哪项任务好 + 引对应图表/误差 + 来自哪个结构」，不写「精度高、实用性强」。
- 局限：用「局限—何时失效—偏差方向—当前缓解—可执行改进」闭环；主动写 2–3 条真实局限。
- 推广：哪些结构可迁移、哪些参数需重新标定。

## 4. CEWL 结果段与结果呈现

每个结果段按 **CEWL** 组织：
- **C (Claim 结论)**：发现了什么，一句话；
- **E (Evidence 证据)**：具体数值、表号、图号、检验量；
- **W (Warrant 担保)**：为什么该证据支持结论（机理/统计推理）；
- **L (Limitation 边界)**：适用范围与失效条件。
- 禁止补造数值/文献/实验/参数来源/因果；证据不足就停笔、列缺口，不硬写。

CEWL 写作下任务时给 AI 限定：允许主张(C-id)、允许证据(图表/数据行)、关键数字、Warrant、Limitation、禁止项、输出一个忠实段落 + 一行待补证据。

## 5. 图、表、公式、参考文献、附录

### 图
- 数据图用 Python(matplotlib) 由正式结果生成、输出矢量(PDF/SVG)；示意图/流程图用 Visio/AxGlyph/PPT/draw.io（含公式推荐 AxGlyph）。
- 一图一判断；信息流方向固定、全篇色义/线型一致；**图题写主要关系或结论，不写「流程图」**；坐标轴有名称/单位/刻度，图例、样本量、场景完整。
- 机制图解释方程约束、诊断图证明估计与残差、搜索图证明候选域与最优性、敏感性图给稳定区间与失效阈值。
- 禁：模糊截图直接贴、手改数据图数值、3D 装饰二维数据、只画拟合曲线不画观测点/残差/基线、截断坐标夸大差异、最终版面需放大才看清；几何示意图必须几何正确。

### 表
- 一律三线表(booktabs)，无竖线网格；表头含变量/单位/情景/统计口径；数字来自结果文件、不手改；显示精度按题面，内部保留原始精度。

### 公式与字形
- 标量斜体、常量与单位正体、向量粗体，矩阵/集合字形全书一致；公式编号连续；每个图表公式都在正文被引用。

### 参考文献
- 国标格式、正文首次使用处标 [n]；成熟方法(SG 平滑、Huber、L-M、AHP 等)都引来源；5–10 篇；赛题附件不作文献。
  - 期刊：作者. 题名[J]. 刊名, 年份, 卷(期): 页码. / 书：作者. 书名[M]. 版次. 地: 社, 年份. / 网页标准：机构. 标题[EB/OL]. 日期[引用日]. 链接.

### 附录代码
- 完整、可从原始数据一键复现正文全部数值与图表：配置→预处理→模型→目标/约束→求解→验证→导出→主入口；不截图、不省略、不「其余同理」；固定种子、相对路径、注明环境与依赖版本。
- 可加「公式—代码—结果追溯表」：数学对象↔式号↔函数↔输出字段↔正文图表号。
