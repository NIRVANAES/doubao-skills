# 番茄小说作家专区

## 概述

通过浏览器自动化连接番茄小说作家专区（`https://fanqienovel.com/writer`），完成作者后台日常操作：登录、发布/更新章节、查看作品数据、管理作品、读者互动。

## 执行通道

- 唯一页面控制方式：`computer_use_tool` 且 `plane="bu"`，代码内 `import seed_browser_use as bu`。动手前先 Read `browser-use-automation` 的 SKILL.md 并遵守其 ref-first 规则（观察→取 ref→动作→再观察）。
- 本 Skill 是浏览器操作型，不做 Python 爬虫 / 站点 API 集成。
- 页面随时可能改版：始终以实时 `bu.snapshot()` / `bu.find()` 观察到的元素为准，把菜单/按钮名称当作语义目标，不假设固定选择器或坐标。

## 核心工作流

### 1. 打开作家专区
- `bu.navigate("https://fanqienovel.com/writer")` → `bu.wait_for_load()` → `bu.snapshot()` 观察当前状态。

### 2. 登录（必须用户接管）
- 作家专区必然需要登录。一旦出现登录页 / 扫码 / 验证码 / `blocked=auth`（登录表单、二维码、验证码弹窗挡住操作），**下一个工具调用必须是** `interaction.request_action(type="browserControl")`，提示用户接管浏览器完成手机号验证码或抖音扫码登录，登录完成后交回控制权。
- 严禁代输手机验证码、密码等敏感信息；交回后 `bu.snapshot()` 确认已进入后台，再用新 ref 继续。

### 3. 登录后确认
- 确认进入作家后台（出现"创作 / 数据中心 / 我的"等入口）。若仍停在登录页，再次请求接管，不得假装已登录。

## 任务

### 发布 / 更新章节
1. 进入创作 / 作品列表，定位目标作品。
2. 进入"章节管理"，点"新建章节 / 写新章节"。
3. 填写章节名与正文（正文较长时分块 `bu.fill_input`；若正文在本地文件，先读取内容再填入）。
4. 确认发布设置（立即 / 定时发布，免费 / 收费）后准备发布。
5. 发布是外部副作用：提交前调用 `interaction.request_action(type="browserControl")` 让用户确认或接管完成，之后验证发布结果。

### 查看作品数据
1. 进入"数据中心 / 作品数据 / 我的作品"。
2. 用 `bu.get_page_text()` / `bu.read_all()` 读取各书阅读量、收藏、追读、收益等指标。
3. 按需切换时间范围（今日 / 近 7 日 / 累计），汇总后按用户要求格式输出。
4. 只读不写；需向用户展示时用 `bu.screenshot()` 截取对应区域。

### 管理作品
1. 进入作品设置 / 管理页（书名、简介、封面、签约状态、上下架等）。
2. 按用户指令修改对应字段，改后保存并验证。
3. 封面上传用 `bu.upload_file`；若需用户自选本地文件，用 `interaction.request_action(type="fileUpload")`。

### 读者互动
1. 进入"评论 / 消息 / 互动"区。
2. 读取读者评论，需要回复时先向用户确认文案与范围，再接管发布。
3. 只汇报用户要的信息，不擅自对外回复。

## 边界与失败处理

- 元素找不到 / 超时：重新观察页面，用不同语义词 `bu.find()`，不盲试坐标，不重复无脑点击。
- 登录态丢失：重新请求浏览器接管完成登录。
- 所有发布 / 回复 / 修改 / 上传等副作用动作前，先征求用户确认。
- 页面被验证码等拦截时一律交回用户，不得绕过。
