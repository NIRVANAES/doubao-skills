# 常见问题与排查

> 遇到异常先对照本表；仍无法解决时，重新观察页面后按语义继续，必要时请求用户接管。

## 登录相关

### 打开作家专区停在登录页 / 跳转登录
- 属正常：作家专区必须登录。调用 `interaction.request_action(type="browserControl")` 让用户扫码或验证码登录。
- 交回后仍停在登录页：重新请求接管，不要假装已进入后台。

### 登录后操作又要求重新验证
- 登录态过期或被风控拦截。重新请求浏览器接管完成验证，再继续当前任务。

## 页面与元素

### 找不到"新建章节 / 数据中心"等入口
- 番茄后台可能按账号 / 角色显示不同菜单。先用 `bu.get_page_text()` 全览后台导航，用相近语义词 `bu.find()` 搜索（如"创作 / 作品 / 数据 / 我的"）。
- 可能入口藏在个人头像下拉、侧边栏折叠、或"更多"菜单里，`bu.hover()` 展开后观察。

### 点击无反应 / 按钮像没生效
- 先 `bu.snapshot()` 看是否有弹窗、遮罩或 toast 拦截；确认目标元素新 ref 后再点一次。
- 不要连续无脑点击；观察后再决定。

### ref 失效（BU_REF_STALE / BU_REF_UNSCOPED）
- 页面导航、加载、弹窗都会让旧 ref 失效。重新 `bu.snapshot()` 取新 ref。

### 页面加载超时 / 白屏
- `bu.wait_for_load()` 超时后先 `bu.page_info()` / `bu.snapshot()` 看实际状态，再决定 `bu.navigate("reload")` 或等待。

## 内容与数据

### 正文很长，编辑器输入被截断
- 分段输入：先聚焦编辑器，分多次 `bu.type` 或 `bu.fill_input`，每次输入后短暂观察。
- 若编辑器是富文本（contenteditable），聚焦后直接 `bu.type`；必要时用 `bu.js` 兜底（先试正常路径）。

### 数据读不全 / 只有一页
- 检查是否有分页或"查看更多"，逐页读取；注意时间范围筛选是否覆盖目标区间。

### 截图想截某个区域
- 用 `bu.screenshot(ref=...)` 截元素级区域；要整页先滚动再 `bu.screenshot()`。

## 权限与安全

### 需要用户选择本地文件（封面等）
- 用 `interaction.request_action(type="fileUpload")`，不要猜测本地路径。

### 是否需要为每次发布单独确认
- 是。发布章节、回复评论、删除章节、上下架等副作用操作，提交前都让用户确认或接管。
