# 番茄作家专区操作指南

> 本文件是 `fanqie-writer-zone` 的详细操作手册，仅在执行具体任务时按需读取。
> 所有页面元素名称均为语义目标，页面改版时以实时 `bu.snapshot()` / `bu.find()` 结果为准。

## 1. 登录流程（首次 / 登录态失效）

1. `bu.navigate("https://fanqienovel.com/writer")`，`bu.wait_for_load()`。
2. 观察是否进入登录态：
   - 出现手机号 / 验证码登录框、二维码、或跳转到 `main/writer/login` → 需要登录接管。
   - 已显示后台入口（创作、数据中心、我的等）→ 直接进入对应任务。
3. 登录接管：调用 `interaction.request_action(type="browserControl")`，`display_message` 写明"番茄小说作家专区需要登录，请接管浏览器完成手机号验证码或抖音扫码登录，完成后把控制权交回"。
4. 交回后 `bu.snapshot()` 重新确认登录态与当前页，再继续。
5. 提示：番茄支持手机号验证码登录与抖音扫码登录，推荐扫码最快。

## 2. 发布 / 更新章节

### 定位与进入
- 后台一般有"创作"或"作品管理"入口 → 进入作品列表 → 点目标作品。
- 若列表有搜索框，用书名 `bu.fill_input` 快速定位。

### 新建章节
- 进入该作品的"章节管理 / 目录"页。
- 找"新建章节 / 写新章节 / 添加章节"按钮，点击进入编辑器。

### 填写内容
- 章节名输入框：输入章节标题。
- 正文编辑区：正文较长时，先 `bu.get_page_text()` 或读取本地正文文件，再按内容长度分批填入（长文本用 `bu.fill_input` 或先聚焦编辑器再逐段 `bu.type`）。不要一次性贴入超出编辑器容量的内容。
- 如有"定时发布 / 立即发布"和"免费 / 付费"等开关，按用户指令设置。

### 发布确认
- 发布是外部副作用：提交前调用 `interaction.request_action(type="browserControl")`，让用户确认章节标题、内容、发布方式后在页面上点击发布。
- 交回后验证：章节是否出现在目录中、状态是否正确。

## 3. 查看作品数据

### 数据入口
- 后台一般有"数据中心 / 作品数据 / 数据"入口；也可从作品管理页进入单书数据。
- 常见指标：阅读量（新增阅读 / 总阅读）、收藏（新增 / 总收藏）、追读、评论、收益 / 稿费、完读率等。
- 时间范围：页面通常提供"今日 / 昨日 / 近 7 日 / 近 30 日 / 累计"切换，按需点击切换。

### 抓取与输出
- 用 `bu.read_all()` 读取表格数据（如 `table tbody tr`），或 `bu.get_page_text()` 取整页文字。
- 多个指标混在页面上时，先 `bu.snapshot()` 或 `bu.get_page_text()` 全览，再决定如何结构化提取。
- 输出时标注统计口径与时间范围（如"近 7 日新增阅读 1234"），不做超出页面数据的推断。

## 4. 管理作品

### 可管理内容
- 基础信息：书名、作品简介、分类 / 标签、封面图。
- 状态：连载中 / 完结 / 暂离，上下架，签约相关设置。
- 章节：删除 / 排序 / 改标题（删除属高风险操作，先向用户确认）。

### 操作方式
- 进入"作品设置 / 编辑作品"页，修改字段后点"保存"，保存后重新读取确认生效。
- 封面图上传：`bu.upload_file(ref, 本地图片绝对路径)`；若不确定本地路径，用 `interaction.request_action(type="fileUpload")` 让用户选择。
- 任何删除 / 上下架操作前，先向用户确认并说明影响。

## 5. 读者互动

### 查看评论
- 进入"评论 / 互动 / 消息"区（可能在作品管理或单独入口）。
- 用 `bu.read_all()` 或 `bu.get_page_text()` 读取评论列表，按用户要求提取（全部 / 最新 / 按书）。

### 回复
- 回复是对外发布：先向用户确认回复对象与文案，再通过 `interaction.request_action(type="browserControl")` 让用户接管完成，或确认后代理执行并验证。

## 6. 通用技巧

- 页面跳转后 ref 失效：任何导航后重新 `bu.snapshot()` 取新 ref。
- 弹窗 / 浮层：先 `bu.snapshot()` 看弹窗内元素再操作，避免点到遮罩。
- 分页：数据列表分页时用"下一页"按钮逐页读，或用 `bu.read_all(limit=...)` 控制读取量。
- 懒加载：长列表先滚动再读，避免漏数据。
